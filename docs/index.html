How it works

You start each day with a pot of 100 and one bullet in six chambers. Fire and survive, the pot doubles and another bullet is loaded. Fire and die, you lose the lot until tomorrow. Cash out whenever you like.

  • Cashed money is pending until the next reset at midnight UTC+1, so you cannot re-stake it the same day.
  • Spend banked money on High Roll dice: beat the bot for x2, win on a six for x3, tie and you keep your stake. Five rolls a day.

Commands

/rouletteStart or resume today's run.
/dice bet:<amount>Play High Roll with banked money.
/balanceYour money, run, and rolls left. Only you see it.
/topTop ten players.

Self-host

Needs Bun. Storage is one SQLite file through bun:sqlite — nothing to compile.

$ git clone https://github.com/anas1412/discord-russian-roulette
$ bun install
$ cp .env.example .env   # add your token and client ID
$ bun run deploy
$ bun start
