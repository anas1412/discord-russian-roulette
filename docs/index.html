Three rules that make it hurt

The catch

RULE 01

One run a day

The revolver resets at midnight UTC+1. Die on your first pull and that is your whole day — there is no second attempt, no buying back in.

RULE 02

Winnings sit overnight

Cashing out moves money to pending. It only becomes spendable at the next reset, so you can never gamble today's winnings on today's dice.

RULE 03

The sixth is certain

After five survivals every chamber is loaded. The bot still offers the pull, labelled certain death — because hiding the option would be a lie about the odds.

Run your own

Self-host
in four steps

Needs Bun. Storage is a single SQLite file through bun:sqlite, so there is nothing to compile and no database to stand up.

  1. Clone and install

    $ git clone https://github.com/anas1412/discord-russian-roulette
$ cd discord-russian-roulette
$ bun install

  2. Add your credentials

    Take the token from Bot → Reset Token and the client ID from General Information in the Discord Developer Portal.

    $ cp .env.example .env
# DISCORD_TOKEN=...
# DISCORD_CLIENT_ID=...

  3. Register the commands

    Set DISCORD_GUILD_ID while developing and they appear instantly. Leave it empty to go global, which takes up to an hour.

    $ bun run deploy

  4. Start it

    Invite the bot with the bot and applications.commands scopes. No privileged intents needed.

    $ bun start
